# FakeBodyscan

整人用的假「人體蟲蟲掃描系統」。把手機用傳輸線接上筆電,假裝手機是感應器,貼在小孩肚子上「掃描」,筆電就會嗶嗶叫並播出蟲蟲影片。

手機只是道具,不需要安裝或打開任何東西。整個程式就是一個網頁([index.html](index.html))。

## 第一次設定

用筆電的 **Chrome 或 Edge** 打開網頁,依畫面下方的按鈕操作:

1. **配對感應器**:先把手機用傳輸線接上筆電,按按鈕,在清單裡選你的手機。之後瀏覽器會記得它。
2. **選擇影片**(可略過):已內建一段蟲蟲影片。想換成別的再按這個挑檔案,挑的影片只存在你自己的瀏覽器裡,不會上傳。
3. **全螢幕**:設定區塊會隱藏,只剩掃描系統的畫面。

配對完先把手機拔掉。

## 表演

1. 畫面顯示「請接上感應器…」。
2. 把手機插上傳輸線:開始「掃描中」,慢速嗶聲。
3. 把手機貼在肚子上。8 秒後自動「發現蟲蟲」:急促的 BI BI BI,播放影片。
4. 按空白鍵:「蟲蟲已全部清除」。
5. 拔掉手機,回到待機。

## 鍵盤(備用)

偵測不到傳輸線時,整套流程也能用鍵盤操作。

| 按鍵 | 作用 |
|---|---|
| 空白鍵 | 下一步(待機 → 掃描 → 發現蟲蟲 → 清除 → 待機) |
| N | 沒有蟲蟲,直接跳到清除畫面 |
| R | 重來 |
| F | 全螢幕 |

## 注意

- 要先在頁面上點過或按過一次鍵,瀏覽器才允許發出聲音。
- 偵測傳輸線用的是 WebUSB,只有 Chrome、Edge 這類瀏覽器支援。
- 掃描秒數可以改 index.html 裡的 `SCAN_SECONDS`。
